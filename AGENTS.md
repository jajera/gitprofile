# Agent notes (Cursor and Kiro)

## Resume toolkit

Career facts: `resume/pool/`.

When building a resume from a JD:

1. Draft plain text at `resume/drafts/<slug>.txt` first.
2. Use natural English and ATS-friendly ASCII (hyphens, not em dashes).
3. Do not invent experience. Pool only.
4. No phone or email. LinkedIn, GitHub, website only.
5. PDF under `resume/out/` only when the user says the draft is final.
6. Render with `resume/scripts/render_pdf.py`. `Technologies:` lines are dark (bold label + body ink), not muted grey.

See `.cursor/rules/resume.mdc`, `.cursor/skills/resume-from-jd/`, and `.kiro/steering/resume.md`.
