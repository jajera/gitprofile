# Product

gitprofile is John Ajera's personal CV site (Astro) at gitprofile.johna.kiwi, plus a local resume toolkit.

The public site renders profile content from the GitHub profile README. The resume toolkit under `resume/` holds a standalone career pool and produces NZ-focused, JD-matched resumes.

Priorities:

- Honest, source-backed career facts only (the pool)
- No phone or email in generated materials; LinkedIn, GitHub, and website only
- Draft resumes as plain text first; PDF only when explicitly requested as final
