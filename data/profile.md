## About Me

I'm a Platform Engineer based in Wellington, New Zealand, passionate about automation, cloud-native technologies, and modern development practices. My journey in IT has evolved from a Windows background, starting with physical servers, then virtualization (Windows and Linux), and now fully embracing cloud-native technologies.

I believe in sharing knowledge and building reusable solutions that help others in their journey. I'm actively working on creating modular infrastructure components, reusable workflows, and documentation to make cloud infrastructure more accessible.

* 🔭 **My Current Focus**
  * Platform Engineering - Building and maintaining developer platforms and tooling
  * Infrastructure as Code - Terraform modules and best practices
  * Cloud Platforms - AWS and Azure architecture and services
  * Containerization - Docker, Podman, DevContainers, ECS, and EKS
  * CI/CD Automation - GitHub Actions, GitLab CI/CD, and reusable workflows
  * Developer Experience - DevContainers and development tooling
  * Open Source Contributions

* ✨ **Technical Skills**
  * **Cloud Platforms:** AWS, Azure
  * **Infrastructure as Code:** Terraform, Ansible, Puppet, Chef
  * **Containers:** Docker, Podman, DevContainers, ECS, EKS
  * **CI/CD:** GitHub Actions, GitLab CI/CD, Jenkins
  * **Scripting:** Bash, PowerShell, Python, Ruby, Go
  * **Monitoring:** Datadog, Grafana

* 🌱 **Continuous learning** and adding skills to my toolkit
* ❓ **Ask me about** AWS, Azure, Terraform, GitHub Actions, DevContainers, Infrastructure as Code, Platform Engineering
* ⚡ **Fun fact:** Love building reusable infrastructure components and sharing knowledge with the community
